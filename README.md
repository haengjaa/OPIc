# 🎙️ OPIc 스피킹 연습 웹앱 (Gemini 무료 버전) — 설치·배포 가이드

AI와 영어로 실시간 음성 대화를 하며 OPIc을 연습하는 앱이에요. 연습 방식은 3가지예요.

| 모드 | 내용 |
|---|---|
| 👩‍🏫 지나 코칭 (8단계) | 내 스크립트에서 무작위로 고른 상황으로 튜터 지나가 미션 → 시연 → 롤플레이 → 피드백 → 응용 롤플레이 → 종합 피드백 → 따라 말하기 → 마무리를 진행 |
| 🎤 OPIc 주제별 | 면접관 Ava가 내 스크립트 주제(또는 직접 고른 주제)로 OPIc 질문 |
| 📋 OPIc 미니 모의고사 | 자기소개부터 롤플레이까지 약 10문항 |

끝나면 한국어 피드백(추정 등급, 고칠 문장, 내 스크립트 활용도 등)을 받을 수 있어요.
Google Gemini API의 **무료 등급**으로 동작해요.

## 📁 파일 구성

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 전체 (설정 → 대화 → 피드백), 마이크·스피커 처리 |
| `api/token.js` | 서버: 진짜 API 키를 숨긴 채 임시 열쇠 발급 + 면접관 역할 지시문 |
| `api/feedback.js` | 서버: 대화 기록을 받아 한국어 피드백 생성 |
| `api/mission.js` | 서버: 스크립트로 지나의 "오늘의 미션" 카드 생성 |
| `lib/prompts.js` | AI에게 주는 지시문 모음 (Ava 면접관, 지나 8단계 등) — 말투·규칙을 바꾸고 싶으면 여기 |
| `lib/common.js` | 서버 파일들이 같이 쓰는 도구 |
| `default-script.txt` | 기본으로 들어있는 내 스크립트 |
| `script-parser.js` | 스크립트를 주제별 항목으로 나누고 무작위로 고르는 기능 |
| `manifest.json` | 휴대폰에 앱으로 설치할 때 쓰는 앱 이름·아이콘 정보 |
| `sw.js` | 앱 설치를 가능하게 해주는 파일 (서비스 워커) |
| `icons/` | 앱 아이콘 그림들 |
| `local-server.js` | 내 컴퓨터에서 테스트할 때만 사용 |
| `.env.example` | 비밀 설정 예시 (복사해서 `.env`로 이름 바꿔 사용) |

## 1단계. Gemini API 키 만들기 (무료)

1. https://aistudio.google.com 접속 → 구글 계정으로 로그인
2. **Get API key**(API 키) 메뉴 → **Create API key** → 키 복사 (메뉴 위치는 화면 개편으로 바뀔 수 있어요)
   - 메모장에 저장해두세요. **절대 다른 사람에게 보여주지 마세요.**
3. (권장) 같은 화면에서 결제(Billing)를 **연결하지 않은 상태**로 두세요.
   결제를 연결하지 않으면 무료 등급으로만 동작해서 요금이 나올 일이 없어요.

## 2단계. 내 컴퓨터에서 테스트 (선택)

Node.js 20.6 이상이 필요해요 (확인: 명령 프롬프트에서 `node --version`).

1. 이 폴더를 원하는 위치에 풀기 (예: `C:\projects\opic-voice-app`)
2. `.env.example` 파일을 복사 → 이름을 `.env`로 변경 → 메모장으로 열어 키와 비밀번호 입력
3. VS Code 터미널(또는 명령 프롬프트)에서 이 폴더로 이동 후:
   ```
   npm start
   ```
4. 크롬에서 http://localhost:3000 열기 → **시작하기** → 마이크 허용

## 3단계. Vercel에 배포 ('오늘의 사설' 때와 같은 방식)

1. 이 폴더를 GitHub에 새 저장소로 올리기 (`.env`는 자동으로 제외돼요)
2. https://vercel.com → **Add New → Project** → 방금 만든 저장소 **Import**
3. **Environment Variables**에 아래 2개 추가 후 **Deploy**
   - `GEMINI_API_KEY` = 내 Gemini 키
   - `APP_PASSWORD` = 내가 정한 비밀번호
4. 배포된 주소(https://….vercel.app)로 접속 → 비밀번호 입력 → 시작!
   - 휴대폰에서도 돼요. (마이크는 https 주소에서만 동작 — Vercel은 자동 https)

> 💡 환경변수를 나중에 바꾸면 **Deployments → 최신 배포 → ⋯ → Redeploy** 해야 적용돼요.

> 💡 이미 배포했다면: 새 파일들(`manifest.json`, `sw.js`, `icons` 폴더, 바뀐 `index.html`·`local-server.js`)을
> GitHub 저장소에 올리기만 하면 Vercel이 자동으로 다시 배포해요.

## 4단계. 휴대폰에 앱으로 설치하기

배포된 주소(https://….vercel.app)를 휴대폰에서 열고:

**아이폰 (Safari로 열어야 해요)**
1. **공유 버튼(□↑)** 누르기 (iOS 버전에 따라 아래쪽에 있거나 **⋯ 버튼** 안에 있어요)
2. 목록을 내려서 **홈 화면에 추가** → 오른쪽 위 **추가**
3. 홈 화면에 생긴 **OPIc 연습** 아이콘으로 실행

**안드로이드 (크롬)**
1. 화면 위에 나오는 노란 안내의 **📲 앱으로 설치하기** 버튼 누르기
   (안 보이면 오른쪽 위 **⋮ 메뉴 → 홈 화면에 추가** 또는 **앱 설치**)
2. 홈 화면에 생긴 **OPIc 연습** 아이콘으로 실행

처음 실행할 때 **마이크 허용**을 눌러주세요. 비밀번호는 한 번 입력하면 기억돼요.

**휴대폰에서 쓸 때 팁**
- **이어폰(유선·블루투스) 사용을 강력 추천**해요. 스피커로 들으면 소리가 작거나 마이크에 섞일 수 있어요.
- 대화 중에는 화면이 자동으로 꺼지지 않게 해뒀어요 (지원하는 휴대폰에서만).
- 대화 중에 다른 앱으로 넘어가면 연결이 끊길 수 있어요. 연습할 땐 앱 화면을 켜둔 채로 해주세요.

## 📄 내 스크립트 사용하기

- 앱에는 `default-script.txt`(내가 준 스크립트)가 기본으로 들어 있어요.
- 새 스크립트로 바꾸려면 앱의 **내 스크립트 → 📄 스크립트 파일 바꾸기**에서 `.txt` 파일을 고르세요.
  그 휴대폰(브라우저)에 저장되고, **↩ 기본 스크립트로**를 누르면 원래대로 돌아가요.
- 이렇게 적으면 항목이 잘 나뉘어요:
  - `▶ 공원가기` → 큰 주제
  - `[집근처 한강공원 > 분위기 > …]` → 답변 하나 (대괄호로 시작하는 줄)
  - 제목에 `전화편`, `질문`, `묻기`, `약속`, `구매`, `Ask me`가 있거나 `Q.`로 시작하면 → 롤플레이
  - `DAY 1`, `FOOD`, `SPORT` 같은 제목 → 핵심 표현 묶음
- 최근에 연습한 주제는 되도록 다시 고르지 않아요.
- 지나 코칭에서는 스크립트의 문법 실수를 고친 문장을 "📌 내 스크립트 교정"으로 보여줘요.
- ⚠️ 스크립트에 이름 같은 개인정보가 있으니 **GitHub 저장소는 Private(비공개)**로 만드세요.

## 🎮 사용법

- 면접관 질문이 끝나면 그냥 말하세요. **2초쯤 조용히 있으면** 답변이 끝난 걸로 알고 다음 질문을 해요.
- 면접관이 말하는 동안에는 내 마이크 소리를 보내지 않아요 (스피커 소리가 다시 들어가 대화가 꼬이는 것 방지).
  면접관 말을 끊고 싶으면 **⏭ 다음 질문**을 누르세요.
- **지나 코칭**: 화면의 미션 카드를 보고 "시작"이라고 말하면 시연이 시작돼요. 지나가 묻는 말에 "네", "Yes"로 대답하며 단계를 진행해요.
  **⏭ 다음 단계** 버튼으로 다음 단계로 넘어갈 수 있어요.
- **🔁 다시 들려줘**: 방금 말 다시 듣기
- **■ 종료 + 피드백**: 대화를 끝내고 한국어 피드백 받기
- 한 번 대화는 **최대 15분** (Gemini 제한). 14분 30초에 자동 종료되고 피드백이 나와요.

## 🛠️ 문제 해결

| 증상 | 해결 |
|---|---|
| "비밀번호가 틀렸어요" | Vercel의 `APP_PASSWORD`와 똑같이 입력했는지 확인 |
| "API key not valid" | `GEMINI_API_KEY` 값 확인 (앞뒤 공백 없이) |
| "quota" / "429" / "RESOURCE_EXHAUSTED" | 무료 사용량을 다 썼어요. 잠시(또는 다음 날) 후 다시 시도. 내 한도는 AI Studio에서 확인 |
| "연결 실패" / 모델 관련 오류 | Vercel 환경변수 `LIVE_MODEL`에 다른 모델 지정 (예: `gemini-3.1-flash-live-preview`) 후 Redeploy |
| 미션 카드·피드백만 오류 | 환경변수 `TEXT_MODEL`에 다른 모델 지정 (예: `gemini-3.5-flash-lite`) |
| 지나가 단계를 건너뛰거나 섞음 | **⏭ 다음 단계** 버튼 사용, 또는 "Let's go back to step 3"처럼 말로 요청 |
| 마이크 권한 오류 | 주소창 왼쪽 자물쇠 🔒 → 마이크 → 허용 |
| 면접관 소리가 안 들림 | 볼륨 확인, 크롬 최신 버전 사용 |
| 말이 너무 빨리 끊김 / 너무 늦게 반응 | `api/token.js`의 `silenceDurationMs: 2000` 숫자 조절 (1000 = 1초) |
| 아이폰에 "홈 화면에 추가"가 없음 | 카카오톡·네이버 앱 안의 브라우저가 아니라 **Safari**로 열었는지 확인 |
| 휴대폰에서 마이크가 안 됨 | 아이폰: 설정 → (앱 →) Safari → 마이크 → 허용 / 안드로이드: 크롬 → 사이트 설정 → 마이크 |
| 앱을 고쳤는데 휴대폰에 안 바뀜 | 앱을 완전히 껐다 다시 켜기. 그래도 안 되면 `sw.js`의 `VERSION`을 `opic-v2`처럼 바꿔서 다시 올리기 |

## ⚠️ 꼭 알아두세요

- **무료 등급에서는 대화 내용(내 목소리·글자)이 Google의 서비스 개선에 쓰일 수 있어요.**
  개인정보(실명, 주소, 회사명 등)는 말하지 않는 걸 추천해요.
- 무료 사용량 한도는 계정·모델마다 다르고 바뀔 수 있어요. AI Studio에서 확인하세요.
- 피드백의 "예상 등급"은 AI의 **추정**일 뿐, 실제 OPIc 채점과 다를 수 있어요.
- 대화 내용은 앱에 저장되지 않아요 (새로고침하면 사라짐).
